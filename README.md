# 야생동물 스포츠 하는 날

`야생동물 스포츠 하는 날`은 제한 시간 안에 야생동물과 관련된 미니게임을 최대한 많이 클리어하며 점수를 기록하는 PC 싱글플레이 종합 미니게임입니다.

## 게임 컨셉

- 야생동물 컨셉의 병맛 미니게임
- 랜덤하게 등장하는 미니게임 진행
- 빠른 선택과 짧은 플레이 반복
- 제한 시간 안에 높은 점수 달성
- 서버 점수 저장과 명예의 전당 방향

## 기본 흐름

1. 게임 시작
2. 연습모드 / 게임모드 선택
3. 스테이지 후보 확인
4. 플레이어 선택
5. 미니게임 플레이
6. 다음 미니게임 반복
7. 결과 확인

## 기본 조작

- 이동: WASD
- 점프: Space
- 물기: 좌클릭

미니게임에 따라 조작은 달라질 수 있습니다.
