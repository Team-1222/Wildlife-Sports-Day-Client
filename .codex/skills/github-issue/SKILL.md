# GitHub Issue Creator

현재 Git 저장소에 GitHub 이슈를 생성한다. Unity 게임 개발 환경을 기준으로 동작한다.

## 언어 규칙

- 이슈 제목: `[라벨] 한글 설명`
- 이슈 제목 라벨은 저장소에 존재하는 라벨 이름과 정확히 맞춘다.
- 이슈 본문은 한글로 작성한다.
- 사용자 승인 전에는 이슈를 생성하지 않는다.

## 사용 가능한 라벨

- `UI`: UI 배치/기능 구현
- `Bug`: 오류 수정
- `Chore`: 설정, 패키지, 폴더 정리 등 기타 작업
- `Design`: 그래픽, 화면 구성 작업
- `Docs`: README, 기획서, 주석 등 문서 작업
- `Feature`: 새로운 기능 구현
- `Improve`: 사용자 위주의 기존 기능 개선
- `Minigame`: 개별 미니게임 구현
- `Refactor`: 동작 변경 없이 코드 구조 개선
- `Save`: 설정 및 기록 저장 시스템
- `Test`: 테스트 코드 및 동작 검증

## 워크플로우

### 1단계: 저장소 확인

```bash
gh repo view --json nameWithOwner -q .nameWithOwner
gh api user -q .login
```

### 2단계: 이슈 정보 수집

- 제목: 필수, `[라벨] 한글 설명`
- 본문: 선택. 없으면 템플릿 기반 작성
- 라벨: 내용 기반 자동 결정
- 담당자: 명시하지 않으면 현재 로그인 사용자

### 3단계: 이슈 제목 생성

- `[UI] HUD 배치 구현`
- `[Bug] 스테이지 후보 선택 중 타이머 오류 수정`
- `[Feature] 랜덤 미니게임 선택 흐름 추가`
- `[Minigame] 악어 물기 미니게임 구현`
- `[Save] 최고 점수 저장 시스템 구현`

### 4단계: 본문 작성

Bug 이슈:

```md
## 버그 설명

## 재현 방법
1.
2.
3.

## 예상 동작

## 실제 동작

## 환경
- Unity 버전:
- 플랫폼:

## 참고 사항
```

Feature / Improve / Minigame / Save 이슈:

```md
## 개요

## 목적 및 배경

## 구현 내용
- [ ]
- [ ]
- [ ]

## 참고 사항
```

기타 이슈:

```md
## 개요

## 작업 항목
- [ ]
- [ ]

## 참고 사항
```

### 5단계: 라벨 결정

- UI 배치/기능 구현: `UI`
- 오류 수정: `Bug`
- 설정, 패키지, 폴더 정리 등 기타 작업: `Chore`
- 그래픽, 화면 구성 작업: `Design`
- README, 기획서, 주석 등 문서 작업: `Docs`
- 새로운 기능 구현: `Feature`
- 사용자 위주의 기존 기능 개선: `Improve`
- 개별 미니게임 구현: `Minigame`
- 동작 변경 없이 코드 구조 개선: `Refactor`
- 설정 및 기록 저장 시스템: `Save`
- 테스트 코드 및 동작 검증: `Test`

라벨은 여러 개 적용 가능하다.

### 6단계: 생성 전 확인

사용자에게 다음을 보여주고 확인받는다.

- 제목
- 라벨
- 담당자
- 본문 미리보기

### 7단계: 이슈 생성

```bash
gh issue create \
  --title "<이슈 제목>" \
  --body "<이슈 본문>" \
  --label "<label1>" \
  --label "<label2>" \
  --assignee "<username>"
```

## 에러 처리

- `gh` 인증 안 됨: `gh auth login` 안내
- Git 저장소 아님: 저장소 확인 요청
- 원격 저장소 없음: GitHub 원격 연결 안내
- 라벨 없음: 사용자에게 라벨 생성 여부 확인
- 권한 부족: 저장소 권한 확인 안내
